# v0.9.0 Implementation Plan — Maintain Loop Closure (auto-diagnose)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the Maintain → Plan loop per the AI-Native SDLC playbook: `maintain-exit.sh` calls `loshu-sdlc maintain diagnose` automatically when 3σ is breached; the diagnose step writes a structured incident `intent.md` before the existing fork-and-block logic runs. Loop closes without manual `/sdlc-maintain` invocation. Degraded-mode (no LLM) still closes the loop with structured fields only.

**Architecture:** Two new CLI subcommands (`bands diagnose`, `maintain diagnose`); one shell hook change to `maintain-exit.sh`; one slash-command doc update. **No new daemon. No new persistent state beyond the existing incident `intent.md` and `cycle.json` fields.** LLM integration is explicitly a single-file future swap (deferred per user decision).

**Tech Stack:** Node ≥ 20.0.0, TypeScript 5.4 strict, vitest 1.6, ajv 8 (already wired via `validateArtifact`), bash `set -euo pipefail` hooks, pnpm 9 workspaces, `timeout` (POSIX) for the diagnose-bounded invocation. **No new dependencies.**

**Spec:** `docs/superpowers/specs/2026-09-20-v0.9.0-design.md`
