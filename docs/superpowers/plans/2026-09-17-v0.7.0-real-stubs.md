# v0.7.0 Implementation Plan — Real Git Sync + Rules Foundation + Stub Polish

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Push four `loshu-sdlc` commands from print-only stubs to real implementations (`git sync`, `rules check`, `logs`, `upgrade`); close three v0.6.4 follow-up items (`STAGE_TO_SCHEMA` export + `a.stage` registry fix, drop `merged` from TRANSITIONS, dedupe `readFrontmatter`); produce v0.7.0.

**Architecture:** No new subsystems. All work extends existing files in `packages/cli/src/`. The only new files are `lib/stage-schema.ts` (Stage→schema mapping), `lib/accept/frontmatter.ts` (extracted helper), and test files. `git sync` is the biggest piece — it shells out to `git`/`gh` via `execa` and writes back to `cycle.json` (`platform` + `pr` fields).

**Tech Stack:** Node ≥ 20.0.0, TypeScript 5.4 strict, vitest 1.6, execa 8 (already used by platforms), chalk 5, fs-extra 11, pnpm 9 workspaces.

**Spec:** `docs/superpowers/specs/2026-09-17-v0.7.0-design.md`

## Global Constraints

- Node ≥ 20.0.0 must work (CI matrix runs Node 20).
- pnpm invoked via `npx pnpm@9.0.0 <cmd>` in sandboxes without global pnpm.
- TypeScript strict: `exactOptionalPropertyTypes`, `noUncheckedIndexedAccess` — optional fields need `| undefined`, regex match groups need `!` or `?? fallback`.
- `packages/cli` is `"type": "module"` — ESM imports only; CJS deps need default-import interop: `import fsExtra from 'fs-extra'; const { readFile } = fsExtra;`.
- Conventional Commits (`feat:` / `fix:` / `test:` / `docs:` / `chore:` / `refactor:`).
- Test framework: vitest only; test files live at `packages/cli/tests/**`.
- AJV is already used by `packages/cli/src/lib/validate.ts` via `validateArtifact(name, path)`; reuse the existing import pattern for the 3 schema-based rules.
- `execa` mock pattern for git/gh calls: `vi.mock('execa')` (auto-mock preserves types) + `mockExeca(stdout: string): ExecaReturnBase` helper typed as `Awaited<ReturnType<typeof execa>>`. See `packages/cli/tests/lib/platforms/github.test.ts` for the working pattern.
- For `commands/git.ts`, `git sync --dry-run` is the default in v0.7.0; real execution requires the explicit `--execute` flag.
- Bash hooks: untouched in this plan.
- All work on `main`; one commit per task.
- Never paste tokens/secrets into any file, commit, or report.
