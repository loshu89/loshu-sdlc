# v0.2.0 Rename Report — `@loshu-sdlc/*` → `@loshu89/*`

**Date:** 2026-09-14
**Goal:** Switch the npm scope from `@loshu-sdlc/*` to `@loshu89/*` so it matches the
GitHub repo owner (`loshu89`). This is the third rename: `@loshu-sdlc/*` → `@maxsun1989/*`
(v0.1.1) → `@loshu-sdlc/*` (v0.2.0 Plan B revert) → `@loshu89/*` (this rename).

The motivation: GitHub Packages requires `npm-scope = GitHub-owner`. The repo is now
owned by `loshu89`, so the npm scope must be `@loshu89` to publish cleanly.

## Concerns

### Scope-vs-owner match — should publish cleanly now

GitHub Packages requires `npm-scope = GitHub-owner`. After this rename:

- Repo owner: `loshu89` (user)
- npm scope: `@loshu89`

This satisfies the publish requirement, so `.github/workflows/publish-ghcr.yml`
should now succeed. The previous rename (`@maxsun1989/*` → `@loshu-sdlc/*`)
broke this alignment; this rename restores it.

### No version bump applied yet

The v0.2.0 changeset is a "pending change" in the changesets system. To turn it
into a release, run `pnpm version` (which invokes `changeset version`) followed
by `scripts/release.mjs v0.2.0`. Until then, the workspace packages still carry
their v0.1.x versions in `package.json`.

### Bundled plugin copy is stale but gitignored

`packages/cli/plugin/` is a checked-in copy of `packages/plugin/` that gets
regenerated by `scripts/copy-plugin.mjs` during `pnpm build`. The source edits
in `packages/plugin/` were also mirrored to `packages/cli/plugin/` so the next
build is a no-op, but this directory is excluded from version control (see
`.gitignore`). Same situation as before this rename.

### `.changeset/v0.1.1.md` package entries retargeted

Following the same pattern as the previous rename (see `docs/v0.2.0-rename-report.md`),
the package entries in `.changeset/v0.1.1.md` were updated to reference `@loshu89/*`
instead of `@loshu-sdlc/*`. This preserves the historical record of the v0.1.1
release while keeping `pnpm version` able to resolve package names. If you'd
rather freeze the historical changeset verbatim (with `@loshu-sdlc/*`), revert
just that file.

### `tests/evals/results.json` regenerated

The eval run during verification rewrote the `generatedAt` timestamp and
flipped the `mode` from `strict` to `loose`. This file is intentionally excluded
from the rename commit (it normally gets its own "chore: update eval results"
commit). To commit it, run a follow-up commit.

### `.npmrc` token warning is unrelated

`pnpm install` emits `WARN Failed to replace env in config: ${NPM_TOKEN}` — this
is expected (no `NPM_TOKEN` in the local environment). It does not affect the
install or the rename.
