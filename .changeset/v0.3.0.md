v0.3.0: DAG state machine for every SDLC artifact

- Added `state` field (enum: draft, accepted, iterating, blocked,
  rejected, archived) to all 6 artifact schemas.
- Added `packages/plugin/state-machines/artifact.json` formal DAG.
- Added `loshu-sdlc state` CLI command with `show`, `<stage> <file>`,
  `--transition`, and `--validate` subcommands.
- Hooks (`plan-exit`, `design-exit`, `build-exit`, `deploy-exit`,
  `maintain-exit`) now read and update the state field; enforce the
  cross-stage rule (previous stage must be `accepted`).
- Updated authoring skills and the `/sdlc-status` slash command.
- 18 new tests in `packages/cli/tests/commands/state.test.ts`.
