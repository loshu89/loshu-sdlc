v0.5.0: hook debouncing (PostToolUse settle period)

- Added `packages/plugin/hooks/lib/debounce.sh` exporting
  `gate_should_run <root> <artifact> [settle_seconds]`. Reads
  `.loshu-sdlc/state/.debounce/<artifact>.lastwrite`, computes
  `now - last`, and returns 0 iff that diff is >= the settle period.
- Updated all five stage hooks (`plan-exit`, `design-exit`, `build-exit`,
  `deploy-exit`, `maintain-exit`) to source the library and short-circuit
  with `exit 0` when the gate is still inside the settle window.
  - `plan-exit` gates on `intent.md`
  - `design-exit` gates on `spec.md`
  - `build-exit` gates on `plan.md`
  - `deploy-exit` gates on `REVIEW.md`
  - `maintain-exit` gates on `bands.yaml`
- Added `packages/plugin/hooks/tests/debounce.test.sh` with 13 assertions
  covering first-call, within-settle, post-settle, per-artifact isolation,
  slash-flattening, settle=0, env-var override, and a hook-snippet
  integration test.
- Wired `packages/plugin/package.json` `test` script to the new shell
  test, and added a root-level `pnpm test:hooks` entry.
- Added `docs/internal/hook-debouncing.md` documenting the design
  rationale, marker file layout, and tuning knobs
  (`LOSHU_SDLC_DEBOUNCE_SECONDS` env var, per-call settle argument).

Default settle period is 2 seconds; tune via `LOSHU_SDLC_DEBOUNCE_SECONDS`
or pass a third arg to `gate_should_run`. To disable debouncing set the
settle period to 0.
