v0.4.0: persistent cycle + gate-event state infrastructure (P0-1)

- Added `.loshu-sdlc/state/cycle.json` (cycle counter, per-stage state,
  timestamps, sha fingerprints, origins) and
  `.loshu-sdlc/state/gates.jsonl` (append-only gate event log).
- Added `packages/cli/src/lib/cycle.ts` and `packages/cli/src/lib/gates-log.ts`
  with atomic-write + mkdir-lock semantics.
- Added `loshu-sdlc cycle` subcommand (`status`, `log`, `new`, `set`,
  `archive`, `append-event`).
- Hooks (`plan-exit`, `design-exit`, `build-exit`, `deploy-exit`,
  `maintain-exit`) now persist stage transitions and append gate
  events. `plan-exit` auto-creates cycles. `maintain-exit` forks an
  incident cycle on 3σ incidents.
- Updated `/sdlc-status` slash command to use the new `cycle` subcommand.
- 45 new tests; total count now 109 (was 64).
